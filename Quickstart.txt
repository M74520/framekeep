留影 FRAMEKEEP 2.2.0 · 本机照片筛选

Windows 10 / 11（64 位）：
1. 解压整个 ZIP。
2. 双击 Start-Framekeep.cmd。
3. 首次联网自动安装组件；之后可离线运行。
4. 保持启动窗口开启，浏览器会自动打开。

选择照片文件夹 → 同组网格（默认 4 张，可选 6 / 8 张）→ 数字 1–8 勾选 → Enter 确认本页 → 候选复核 → 导出复制原片。

本组候选跨页常驻。勾选 2–4 张，按 C 大图对比，支持同步放大、拖动和原尺寸细节。
横图、竖图和方图按真实比例自动混排，照片完整显示。卡片底部 ↻ 旋转 90°，可撤销并自动保存；仅调整显示，导出原片不变。
Enter 只处理当前页：选中保留，其余淘汰（待定除外）；未显示照片不变。
Ctrl+Z 一次撤销整页。候选缩略图的 × 取消保留并改为待定。
保留原有候选擂台模式：1 保留 / 2 淘汰 / 3 待定，W 换候选 / B 两张都留。
升级后停止旧启动窗口，重新双击启动；必要时 Ctrl+F5 刷新浏览器。

RAW 自动提取预览，不需要你先转 JPEG。原尺寸细节才解码 RAW。
照片、预览、项目记录都留在本机。不会修改、删除或移动原照片。
每个照片文件夹是独立项目。项目按钮切换，重新扫描复用已有进度。
复制导出时选择原片文件夹之外的位置；已有同名文件会跳过。

发给同事：转发完整 ZIP，对方解压双击启动。双方项目各自保存。
首次安装需访问 Python.org / PyPI / files.pythonhosted.org，无需管理员权限。
macOS / Linux：准备 Python 3.12+ 后运行 sh start.sh。

验证说明：2.2.0 已在 Windows + Chrome 自动验证横竖混排、EXIF 方向、旋转和恢复，以及原有网格和擂台流程。真实 A7C II RAW 画质、Windows 首次安装下载、系统文件夹窗口人工操作未覆盖。详细说明见 README.md 与 VALIDATION.md。
