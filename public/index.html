支持 JPEG / PNG / WebP 等浏览器可解码的图片。RAW 请先生成 JPEG 缩略图。时间优先读取 JPEG 拍摄时间，缺失时使用文件修改时间。相近画面采用本地视觉近似匹配，可调节或手动修正。

仅保存压缩预览和筛选记录到本浏览器；不上传照片、不写入原片。导出进度 JSON 可备份判断，跨浏览器使用时需重新导入照片。导出的 JSON 和 CSV 包含原文件名及拍摄时间，请按个人资料保管。
